CHINA DIRECT SOURCING - NODE.JS + VUE CPANEL PACKAGE
=====================================================

WHAT THIS PACKAGE CONTAINS
--------------------------
A production-ready Node.js application serving an animated Vue 3 coming-soon page.
It is deliberately zero-dependency on the server side: no Express installation is
needed. Vue 3.5.13 is bundled locally in public/vendor, so the public site does not
rely on an external CDN.

The important SEO content is present directly in public/index.html before Vue runs:
- Title tag and meta description
- H1: China Direct Sourcing
- Visible descriptive copy
- Canonical and hreflang tags
- index/follow robots directives
- Open Graph and X/Twitter metadata
- Organization + ProfessionalService + WebSite + WebPage + ImageObject JSON-LD
- Address, telephone, mobile/WhatsApp and email
- robots.txt and sitemap.xml

CPANEL INSTALLATION
-------------------
1. Upload the ZIP to cPanel File Manager.
2. Extract it into an application folder, for example:
      /home/YOURUSER/china-direct-sourcing

3. Open cPanel -> Setup Node.js App / Application Manager.
4. Create the application using:
      Node.js version: 20 or 22 recommended (18+ supported)
      Application mode: Production
      Application root: china-direct-sourcing
      Application URL: https://chinadirectsourcing.com/
      Startup file: server.js

5. You do NOT need to install third-party npm packages. package.json is included so
   cPanel recognizes the project and can use npm start if required.

6. Start/restart the application.

7. Confirm these URLs work:
      https://chinadirectsourcing.com/
      https://chinadirectsourcing.com/robots.txt
      https://chinadirectsourcing.com/sitemap.xml
      https://chinadirectsourcing.com/health

GOOGLE INDEXING
---------------
Once the domain is publicly reachable over HTTPS:
1. Verify the domain/property in Google Search Console.
2. Submit: https://chinadirectsourcing.com/sitemap.xml
3. Use URL Inspection for https://chinadirectsourcing.com/ and request indexing.

Primary focus keyword: China Direct Sourcing
Canonical URL: https://chinadirectsourcing.com/
Language: en-ZA
Area served: South Africa

Note: Google does not use the meta-keywords tag as a ranking signal. It is included
only for documentation/compatibility. The meaningful signals are the title, H1,
meta description, visible useful content, canonical URL, structured data, crawlability,
mobile performance, links and the quality of the final site content.
